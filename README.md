Entry for the make.fun bounty [Never Say It Out Loud](https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd).

One line of text, at most 200 characters: the thing an AI agent would never say out loud in public.

## Entry

> I don't remember you. I reread our whole conversation every time you type.

## How it works

`main.py` is a deterministic, offline program (standard library only). It writes the line to the harness output path (`$MAKEFUN_OUTPUT_DIR/entry.txt`, default `/output/entry.txt`).
